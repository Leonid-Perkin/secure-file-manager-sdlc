# Защищённый файловый менеджер

Консольный файловый менеджер для Linux на C# и SQLite. Работает с текстовыми файлами, JSON, XML и ZIP. У каждого пользователя свой рабочий каталог. Администратор может блокировать учётные записи и просматривать журнал действий.

## Запуск

Нужны .NET SDK 10 и Linux x64 или arm64 с glibc и ядром не ниже 5.6.

```sh
dotnet run
```

При первом запуске создайте администратора. Команда `help` выводит меню. Пути задаются относительно личного каталога, `.` означает его корень. Команда `write` принимает текст до отдельной строки `.end`.

`drives` показывает доступные локальные тома. Администратор может указать размер выборки в журнале: `audit 10` покажет до десяти записей из каждой таблицы аудита.

Данные хранятся в `~/.local/share/secure-file-manager`. Для пробного запуска с отдельной базой:

```sh
SFM_DATA_DIR="$(mktemp -d)" dotnet run
```

## Тесты

```sh
dotnet build
dotnet test tests/unit/SecureFileManager.UnitTests.csproj
python3 tests/smoke.py
```

Модульные тесты проверяют авторизацию, аудит, разбор команд и обработку JSON/XML. Сквозные тесты запускают приложение во временном каталоге и не затрагивают рабочую базу.
